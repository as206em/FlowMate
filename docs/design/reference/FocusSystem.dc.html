Rules
Rows live in one surface with a hairline between each. No card per row.
Three text tones; the title is always the darkest thing in a row.
Only a running timer glows. Nothing else uses the live color.
Timers never stop each other. The sidebar and menu list every live one.
Radius 7 controls, 10 cards, 12 panels. Shadow only on floating panels.
